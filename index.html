  1. MSN‑012026

    PrivacyLayer

    Self‑sovereign identity. Prove you hold a degree, or that you're over 18, without handing over the data behind it — credentials stay on the device, the verifier learns the minimum, and there is no server‑side PII to breach by construction.

    A nine‑package TypeScript monorepo: the security‑critical core runs on Node built‑ins with zero runtime dependencies, alongside Groth16 circuits, a Solidity anchor, three services and a React Native wallet. Consent receipts go into an off‑chain Merkle transparency log — only the root is anchored on‑chain, because a public per‑user log is a correlation oracle and collides with the right to erasure. Every presentation is nonce‑ and audience‑bound, so a captured QR cannot be replayed elsewhere. 344 tests and an end‑to‑end demo run issue → selective disclosure → verify → revoke with no mocked cryptography.

    Stated honestly: the shipped suite is Ed25519 with hash‑based selective disclosure. The BBS+ rail that would make presentations genuinely unlinkable is interfaced but not implemented, so unlinkability is a design property here rather than a delivered one.

  2. MSN‑022026

    SemiCon‑ML — NAFNet‑SR

    Built for the SemiCon AI Hackathon (KLA problem statement 01): recover a clean 256×256 image from a 128×128 input wrecked by multiplicative speckle, additive Gaussian noise and 2× downsampling applied jointly, in random order. Denoise and super‑resolution in one forward pass.

    A NAFNet body verified byte‑identical to the reference implementation, with the input and output ends adapted for the task — a log input transform, because the dominant noise is multiplicative and the log makes it behave additively before the network sees it; a resize‑conv SR head; a bicubic global residual so the network learns only the correction. An FFT notch on known period‑2 and period‑4 bins removes the last artifact for +1.35 dB at no inference cost.
